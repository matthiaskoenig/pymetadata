# Security policy

## Supported versions

Security fixes are only made for the latest release on
[pypi](https://pypi.org/project/pymetadata/). Please update before reporting a
problem.

## Reporting a vulnerability

Please do not report security problems in the public issue tracker. Use
[private vulnerability reporting](https://github.com/matthiaskoenig/pymetadata/security/advisories/new)
instead, or write to konigmatt@googlemail.com.

`pymetadata` is a small academic library maintained by a single maintainer, so
please allow a few days for an initial response. You will be credited in the
advisory unless you prefer otherwise.
