# Release notes for pymetadata 0.6.0
![pymetadata](./_docs/images/favicon/pymetadata-100x100-300dpi.png)

We are pleased to release the next version of pymetadata including the
following changes:

## Features & fixes
- python 3.10 support dropped, python >=3.11 is now required
- mypy replaced by ty for type checking (#69); ty runs in CI, in `tox r -e ty`
  and as a pre-commit hook
- fix the `validate` methods of the SBO, KISAO and ECO enums: the generated
  `isinstance` check compared against a string instead of the enum class, which
  would raise a `TypeError` if that branch were reached
- namespaces without a prefix are skipped when updating the identifiers.org
  registry instead of ending up in the registry with a `None` key
- all `# type: ignore` comments removed from the codebase
- `lxml` and `depinfo` removed from the dependencies (both unused), as well as
  `fastobo` (a transitive dependency of pronto)
- dependencies and development dependencies updated to their latest versions
